## 2026-07-31 — 触发：用户反馈 PPT 溢出+空页+要求联网研究

### 搜索主题与关键发现
1. **PPT design best practices 2025** (pitchworx / slidesorbis / jtrain)
   - 视觉层级：尺寸>颜色>对比>位置，每页先定"主角"
   - 留白是设计元素不是空；学术/商务合理留白 35-40%
   - 配色 ≤3 主色 + 中性色；字体 ≤2 族
   - 三分法构图优于居中；网格系统保证一致性

2. **PPT 留白 不是空白 学术排版** (pptwiki / sohu / allconfs)
   - 主动留白 vs 被动留白：把被动变主动
   - 模块间留白 > 模块内留白（用间距不用细线）
   - 焦点留白：单页一结论占 40-50% 面积（封面/结论页）
   - 学术会议平均留白 38%，不对称布局记忆强度 +17%
   - 6×6 法则：每页 ≤6 行，每行 ≤6 词

3. **PPT 制作流程 自我迭代** (smallppt / worktile / think-cell / pptwiki)
   - 7步框架：故事→行动标题→干净版式→要点组织→图表→格式化→核对
   - 新手流程：目标→大纲→填充→提炼→排版→配色→检查
   - 微软官方：优秀演示经多次修改精简，非一次成型
   - 进阶：拆解优秀案例 + 学基础设计原则（对比/对齐/重复/亲密性）

## 2026-07-31（续）— 触发：自我优化循环定向研究（v7.1）

> 闭环要求：每出现新失败模式即**针对性搜索**，而非泛泛搜一次。本次两类新失败模式 → 定向研究。

### 搜索主题与关键发现
1. **PPT 内容少/空白页 怎么填充**（islide / pptx.cn / itzhengshu）
   - **线框造层次**：色块周围加线框（可错位叠加）→ 立即出层次感
   - **形状叠层级**：多形状叠加 + 渐变/不规则形状制造纵深
   - **复制粘贴法**：对象复制多份制造"数量感"与远近
   - **线条点缀**：引导视觉、平衡版面；棱角多用直线、曲线内容用曲线
   - **色块占位**：纯色/多色块快速填充
   - **icon 助力**：同类型图标统一（实心/空心二选一），iconfont 免费
   - **放大图形**：放大圆/圆角矩形占比，直接减少空白
   - 通用：大字体、加图/插画、引用名言或数据、加解释图表、换背景色

2. **宋体 / 楷体 正式报告 排版 规范**（用户指定"宋体或楷书"）
   - 正式报告正文首选**宋体**（衬线、权威、屏印皆宜）；楷体作书法感标题/强调
   - 字号梯度：标题 20–32pt / 正文 16pt / 标签 14pt / 表 12pt / 页码 10pt
   - 行距 1.2–1.5×，段间距为行距 1.5–2×；≤2 字族

## 实现坑（非联网，自查发现，2026-07-31）
- **python-pptx 中文字体必须显式写 `a:ea`**：`run.font.name` 只写 `a:latin`，中文 `a:ea` 不写 → 中文走系统默认东亚字体，跨机渲染漂移。v7.1 成品 203 个 run 全中此坑（latin=宋体、ea=None）。修复：用 `set_run_font()` 同时写 latin/ea/cs；并加 `detect_font` 自检封死。
- 普通文本框（非卡片）文字溢出 v7.1 未检；`detect_text_overflow_general` 覆盖后首跑即抓出第4页说明文字越界。
