# 引用格式指南

本文件供智能体三（内容生成）、智能体四（质量检测）和智能体五（整合校验）参考，确保引用格式统一。

> **P0-1 引用真实性声明**：本系统严禁虚构参考文献。所有引用必须来自文献池（`reference_pool`）或标注为 `[REF_NEEDED:描述]`。详见 SKILL.md 第 8.7 节。

---

## 一、GB/T 7714（中国国家标准，默认格式）

### 正文引用方式

- 顺序编码制：`[1]`、`[1,3]`、`[1-3]`
- 著者-出版年制：`(张三, 2023)`、`(Smith, 2023)`

### 参考文献著录格式

#### 期刊论文 [J]
```
[序号] 作者. 题名[J]. 刊名, 年, 卷(期): 起止页码.
```
示例：
```
[1] 张三, 李四. 深度学习在自然语言处理中的应用[J]. 计算机学报, 2023, 46(3): 512-528.
```

#### 专著 [M]
```
[序号] 作者. 书名[M]. 版次(第1版不标注). 出版地: 出版者, 出版年: 起止页码.
```

#### 会议论文 [C]
```
[序号] 作者. 题名[C]//会议名. 出版地: 出版者, 年: 起止页码.
```

#### 学位论文 [D]
```
[序号] 作者. 题名[D]. 保存地: 保存单位, 年.
```

#### 电子文献 [EB/OL]
```
[序号] 作者. 题名[EB/OL]. (发布日期)[引用日期]. URL.
```

## 二、APA（美国心理学会格式）

### 正文引用方式
- 单作者：`(Smith, 2023)`
- 双作者：`(Smith & Jones, 2023)`
- 三作者及以上：`(Smith et al., 2023)`
- 直接引用：`(Smith, 2023, p. 15)`

### 参考文献著录格式

#### 期刊论文
```
作者. (年). 文章标题. 期刊名, 卷(期), 页码.
```

#### 专著
```
作者. (年). 书名 (版次). 出版社.
```

---

## 三、MLA（现代语言协会格式）

### 正文引用方式
- `(Smith 15)` — 作者+页码
- `("Title" 15)` — 无作者时用标题

### 参考文献著录格式

#### 期刊论文
```
作者. "文章标题." 期刊名, vol. 卷, no. 期, 年, pp. 页码.
```

#### 专著
```
作者. 书名. 出版社, 年.
```

---

## 四、Chicago（芝加哥格式）

### 正文引用方式
- 脚注/尾注制：正文用上标数字，文末附完整注释
- 著者-日期制：`(Smith 2023, 15)`

### 参考文献著录格式（注释-书目制）

#### 期刊论文（首次引用）
```
John Smith and Karen Jones, "Deep Learning Approaches for NLP," Journal of Computer Science 46, no. 3 (2023): 512.
```

#### 专著
```
Zhihua Zhou, Machine Learning (Beijing: Tsinghua University Press, 2016), 23.
```

---

## 五、IEEE（电气电子工程师学会格式）

### 正文引用方式
- 顺序编码：`[1]`、`[1], [3]`、`[1]-[3]`
- 引用编号按正文出现顺序递增

### 参考文献著录格式

#### 期刊论文
```
[序号] J. K. 作者, "文章标题," 期刊名, vol. 卷, no. 期, pp. 页码, 月 年.
```

#### 会议论文
```
[序号] J. K. 作者, "文章标题," in 会议名, 地点, 年, pp. 页码.
```

#### 专著
```
[序号] Z. H. Zhou, Machine Learning. Beijing, China: Tsinghua Univ. Press, 2016, pp. 23-45.
```

## 六、引用处理流程（P0-1 引用真实性）

### 智能体一（大纲设计）
1. 解析用户提供的参考文献列表（BibTeX/RIS/纯文本），录入 `reference_pool`
2. 若用户未提供，大纲中对应位置标注 `[REF_NEEDED]`
3. 每个文献池条目分配 `ref_id`（如 `ref_001`、`ref_002`）

### 智能体三（内容生成）
1. **引用标记规则**：
   - 从文献池中选取文献：使用 `[CITE:ref_id]` 标记（如 `[CITE:ref_001]`）
   - 文献池中无合适文献：使用 `[REF_NEEDED:需要引用关于XX的文献]` 标记
   - **严禁虚构文献**：不得编造不存在的作者、标题、期刊名
2. 在 metadata.citations 中登记每个引用标记
3. 同一文献多次引用使用相同 ref_id
4. 标记格式必须统一

### 智能体四（质量检测）
1. 检查每个 `[CITE:ref_id]` 标记是否在文献池中存在
2. 检查 `[REF_NEEDED]` 标记是否合理
3. **若发现虚构文献**（引用池中不存在但未标注 REF_NEEDED），直接 `reject`
4. 检查是否有应引用但未引用的关键论点
5. 在共享上下文 citation_registry 中更新状态

### 智能体五（整合校验）
1. 将所有 `[CITE:ref_id]` 标记替换为正式引用编号 `[1]`、`[2]`...
2. 从文献池生成参考文献列表
3. `[REF_NEEDED]` 标记保留，汇总为"需人工核实的引用清单"
4. 统一参考文献格式为目标格式
5. 检查引用编号连续性

## 七、图表/公式占位格式（P1-6）

### 智能体三使用占位标记

#### 图表占位
```
[FIG:type|description]
```
- `type`：`table`（表格）、`chart`（图表）、`diagram`（示意图）
- `description`：图表内容描述

示例：
```
[FIG:table|三种方法在五个数据集上的准确率对比]
[FIG:chart|训练损失随epoch变化曲线]
[FIG:diagram|系统整体架构图]
```

#### 公式占位
```
[EQ:latex_code]
```

示例：
```
[EQ:\mathcal{L} = -\sum_{i=1}^{N} y_i \log(\hat{y}_i)]
[EQ:E = mc^2]
```

### 智能体五替换规则

1. `[FIG:type|description]` → 替换为：
   - 文字描述（描述图表内容）
   - 建议制图方案（推荐使用什么工具/方式制作）
   - 分配图表编号（图 N-N / 表 N-N）
2. `[EQ:latex_code]` → 替换为：
   - 公式编号（(N-N) 格式）
   - 保留 LaTeX 源码供排版使用
3. 生成图表索引和公式索引，附在论文末尾

## 八、引用格式选择决策树

```
用户是否指定引用格式？
├── 是 → 使用指定格式
└── 否 → 论文类型？
         ├── 中文期刊投稿 → GB/T 7714
         ├── 英文期刊投稿 → 查看目标期刊要求
         │    ├── CS/AI 领域 → IEEE
         │    ├── 心理学/教育学 → APA
         │    ├── 人文学科 → MLA 或 Chicago
         │    └── 其他 → APA
         ├── 学位论文 → 学校要求（默认 GB/T 7714）
         └── 课程论文 → 教师要求（默认 GB/T 7714）
```

## 九、需人工核实引用清单格式

最终输出时，所有 `[REF_NEEDED]` 标记汇总为以下格式：

```markdown
## 需人工核实的引用清单

> 以下引用位置在写作时未找到对应文献，请作者人工补充真实参考文献。

1. **位置**：第1章第2段
   **需求描述**：关于深度学习在医学影像中应用的最新综述
   **建议**：检索 PubMed/Google Scholar，关键词 "deep learning medical imaging review 2023-2024"

2. **位置**：第2章第3段
   **需求描述**：Transformer 模型在长文本理解上的性能基准
   **建议**：检索 arXiv，关键词 "transformer long text understanding benchmark"
```
