# 论文结构框架参考

本文件供智能体一（大纲设计）参考，根据论文类型选择对应的章节框架。

> **P0-2 摘要时序倒置**：所有论文类型的摘要/关键词均标记为 `deferred: true`，不进入正常章节流，由智能体五在全文整合后单独生成。

---

## 一、研究论文

适用于：学术论文、会议论文、期刊投稿

### 标准章节结构

```
1. 标题
2. 摘要 [DEFERRED: 由智能体五在全文完成后生成]
   - 研究背景与目的
   - 研究方法
   - 主要发现
   - 结论
3. 关键词 [DEFERRED: 由智能体五提取]
4. 引言
   - 研究背景
   - 问题陈述
   - 研究意义
   - 论文结构概述
5. 相关工作
   - 领域综述
   - 现有方法分类与比较
   - 研究空白识别
6. 方法
   - 总体框架
   - 核心方法/算法
   - 技术细节
   - 创新点阐述
7. 实验
   - 实验设置（数据集、环境、参数）
   - 评价指标
   - 基线方法
   - 实验结果与分析
   - 消融实验（如适用）
8. 讨论
   - 结果解读
   - 与已有工作的对比
   - 局限性分析
9. 结论
   - 主要贡献总结
   - 未来工作方向
10. 参考文献
```

### 字数分配参考（总计 6000-8000 字）

| 章节 | 占比 | 字数范围 | deferred |
|------|------|---------|----------|
| 摘要 | 3% | 200-300 | ✅ 延迟生成 |
| 关键词 | - | 3-6个 | ✅ 延迟生成 |
| 引言 | 15% | 900-1200 | |
| 相关工作 | 15% | 900-1200 | |
| 方法 | 25% | 1500-2000 | |
| 实验 | 25% | 1500-2000 | |
| 讨论 | 10% | 600-800 | |
| 结论 | 7% | 400-600 | |

### 领域特有章节提示

- **CS/AI 领域**：增加"代码与数据可用性"声明、实验环境配置细节
- **医学领域**：增加伦理审查声明、临床试验注册号
- **社科领域**：增加数据来源说明、研究伦理声明
- **人文学科**：增加文本/语料说明、研究方法反思
- **工科领域**：增加实验环境参数、设备型号、仿真配置

## 三、学位论文

适用于：硕士/博士学位论文

### 标准章节结构

```
前置部分:
1. 封面
2. 声明页
3. 中文摘要 [DEFERRED]
4. 英文摘要 (Abstract) [DEFERRED]
5. 目录
6. 图表目录（如适用）

正文部分:
7. 第一章 绪论
   - 研究背景与意义
   - 国内外研究现状
   - 研究内容与目标
   - 论文组织结构
8. 第二章 理论基础/文献综述
   - 核心理论
   - 技术背景
   - 相关研究进展
9. 第三章 研究方法/模型构建
   - 问题定义
   - 方法设计
   - 理论分析
10. 第四章 实验/案例分析
    - 实验设计
    - 结果分析
    - 对比验证
11. 第五章 讨论
    - 结果讨论
    - 局限性
    - 理论与实践意义
12. 第六章 结论与展望
    - 主要贡献
    - 创新点
    - 未来工作

后置部分:
13. 参考文献
14. 附录（如适用）
15. 致谢
16. 攻读学位期间取得成果
```

### 字数分配参考

| 论文类型 | 总字数 | 各章建议 |
|---------|--------|---------|
| 硕士论文 | 30000-50000 | 绪论5000, 文献8000, 方法10000, 实验12000, 结论3000 |
| 博士论文 | 80000-150000 | 绪论8000, 文献15000, 方法3章×10000, 实验3章×12000, 结论5000 |

> **注意**：学位论文字数大，必须启用上下文压缩（`CONTEXT_COMPRESSION=true`），正文以文件形式存储。

## 五、智能体一大纲生成规则

1. 根据用户指定的论文类型，选择上述对应框架
2. 如果用户未指定类型，默认使用"研究论文"框架
3. 根据字数要求，按比例分配各章节字数
4. 每个叶子节点章节必须有：标题、主题描述、预期字数
5. 标注章节间的逻辑依赖关系
6. 关键引用位置用 `citation_hints` 标注，来源标注为 `ref_pool` 或 `[REF_NEEDED]`
7. 如用户有特殊章节需求，在标准框架基础上增删调整
8. **摘要/关键词章节必须标记 `deferred: true`**，不生成写作任务
9. 根据学科领域，参考领域特有章节提示，增补必要章节
10. 大纲产出后暂停，等待用户确认（`REQUIRE_OUTLINE_APPROVAL=true` 时）
