# 质量评审标准详细指南

本文件供智能体四（质量检测）和智能体五（整合校验）参考，提供详细的评分标准。

> **P2-11 原创性维度**：新增"原创性"评审维度，评估研究论文/学位论文的创新点和贡献阐述。
> **P1-7 领域特有维度**：根据学科领域加载额外评审维度，详见 `references/domain_profiles.md`。

---

## 一、智能体四评审维度（章节级）

### 1.1 完整性

| 分数 | 判定标准 | 示例 |
|------|---------|------|
| 5 | 完全覆盖任务要求，且主动补充有价值的关联内容 | 任务要求分析3种方法，写了4种并补充了适用场景对比 |
| 4 | 所有任务要求均覆盖，无遗漏 | 任务要求的每个要点都有对应内容 |
| 3 | 核心要求覆盖，边缘项略有遗漏 | 覆盖了核心论点，但遗漏了次要的实验参数说明 |
| 2 | 遗漏1-2项核心要求 | 缺少对比实验或缺少方法局限性分析 |
| 1 | 遗漏 >50% 核心要求 | 大部分要求内容缺失，章节基本未完成 |

**检查清单：**
- [ ] 任务中列出的每个 content_requirement 是否都有对应内容
- [ ] 关键论点是否有足够支撑
- [ ] 字数是否在约束范围内（±10% 容差）
- [ ] 引用标记是否完整覆盖需要引用的论点

### 1.2 正确性

| 分数 | 判定标准 | 示例 |
|------|---------|------|
| 5 | 无任何错误，数据可溯源，逻辑无懈可击 | 所有数据标注来源，推理链条完整 |
| 4 | 核心内容全部正确，仅有个别非关键笔误 | 核心算法描述正确，仅个别数字笔误 |
| 3 | 核心逻辑正确，存在次要错误 | 方法描述正确，但个别公式符号不一致 |
| 2 | 核心逻辑有误或存在事实错误 | 算法描述有原理性错误 |
| 1 | 严重错误，采用会导致误导 | 结论与实验数据完全矛盾 |

**检查清单：**
- [ ] 数据/统计/公式是否准确
- [ ] 引用的研究结论是否与原文一致
- [ ] 推理逻辑是否自洽
- [ ] 专业术语使用是否准确

### 1.3 学术规范性

| 分数 | 判定标准 | 示例 |
|------|---------|------|
| 5 | 完全符合学术规范，达到可投稿标准 | 格式统一，引用规范，图表规范 |
| 4 | 符合主要规范，个别格式瑕疵 | 引用格式正确，个别图表标题格式不统一 |
| 3 | 主体合规，需少量格式调整 | 标题层级基本规范，个别引用格式不一致 |
| 2 | 多处不符合规范 | 引用格式混乱，标题层级不规范 |
| 1 | 毫无规范可言 | 无结构、无引用、格式混乱 |

**检查清单：**
- [ ] 引用格式是否符合目标格式要求（GB/T 7714 等）
- [ ] 标题层级是否规范（一级、二级、三级标题）
- [ ] 图表是否有编号和标题
- [ ] 术语是否使用规范
- [ ] 是否有口语化表达

### 1.4 语言质量

| 分数 | 判定标准 | 示例 |
|------|---------|------|
| 5 | 学术语言精准，行文流畅，逻辑衔接自然 | 用词精准，过渡自然，无冗余 |
| 4 | 语言通顺，学术风格明确，个别表述可优化 | 整体流畅，个别句子偏长 |
| 3 | 语言通顺但学术性不足，有口语化表达 | 有"大概""可能"等模糊表述 |
| 2 | 语言晦涩或混乱，影响理解 | 长句过多，逻辑不清 |
| 1 | 无法阅读 | 语法错误密集，无法理解 |

**检查清单：**
- [ ] 是否有语法错误
- [ ] 是否有口语化/非正式表达
- [ ] 句式是否多样化（非全部长句或全部短句）
- [ ] 段落是否有明确的主题句
- [ ] 段落间过渡是否自然

### 1.5 原创性（P2-11 新增）

| 分数 | 判定标准 | 示例 |
|------|---------|------|
| 5 | 有明确的创新点声明，贡献阐述充分且突出 | 清晰阐述"本文的创新点在于…"，贡献与已有工作形成鲜明对比 |
| 4 | 有创新性，但阐述不够突出 | 方法有新意，但未明确标注创新点 |
| 3 | 有一定创新性，贡献阐述一般 | 在已有方法上做了改进，但改进幅度有限 |
| 2 | 创新性不足，主要是已有工作的组合 | 简单拼接多个方法，无实质性改进 |
| 1 | 无创新点，纯堆砌已有工作 | 完全照搬已有方法，无任何改进或新贡献 |

**检查清单：**
- [ ] 是否有明确的创新点声明（"本文的创新点/贡献在于…"）
- [ ] 创新点是否与已有工作形成对比
- [ ] 研究贡献是否在引言/方法/结论中一致阐述
- [ ] 是否说明了创新点的学术/实际价值

> **适用范围**：研究论文和学位论文必评；综述论文评估"综述视角的创新性"（如分类框架是否有新意）；课程论文可选（通过 `EVALUATE_ORIGINALITY` 参数控制）。

## 二、智能体五评审维度（全局级）

### 2.1 连贯性

| 分数 | 判定标准 |
|------|---------|
| 5 | 全文一气呵成，章节间过渡自然，逻辑主线贯穿始终 |
| 4 | 主体连贯，个别章节衔接略生硬 |
| 3 | 各章节内部连贯，但章节间衔接有明显断裂 |
| 2 | 多处章节衔接断裂，逻辑主线不清晰 |
| 1 | 章节间完全脱节，无法形成整体 |

**检查清单：**
- [ ] 每章开头是否与上一章结尾有衔接
- [ ] 全文是否有贯穿的逻辑主线
- [ ] 章节排列顺序是否合理（递进/并列/总分）
- [ ] 是否有突然出现的概念（未在前文介绍）

### 2.2 一致性

| 分数 | 判定标准 |
|------|---------|
| 5 | 术语、风格、引用格式全文完全统一 |
| 4 | 主体一致，个别术语或格式不统一 |
| 3 | 有多处术语不一致或格式不统一 |
| 2 | 不同章节风格差异明显 |
| 1 | 全文无一致性可言 |

**检查清单：**
- [ ] 同一术语全文是否使用统一表述
- [ ] 缩写是否在首次出现时定义并全文一致使用
- [ ] 引用编号是否连续无缺
- [ ] 图表编号是否连续
- [ ] 写作风格是否全文一致

### 2.3 呼应性

| 分数 | 判定标准 |
|------|---------|
| 5 | 摘要-引言-正文-结论完美呼应，研究问题全部得到回应 |
| 4 | 基本呼应，个别细节略有出入 |
| 3 | 摘要与正文基本一致，但结论与引言提出的问题部分脱节 |
| 2 | 结论未充分回应引言提出的问题 |
| 1 | 摘要/引言/结论严重脱节 |

**检查清单：**
- [ ] 摘要是否准确概括全文主要内容（P0-2: 摘要由智能体五基于全文生成，应天然呼应）
- [ ] 结论是否回应引言中提出的研究问题
- [ ] 引言中承诺的结构是否在正文中落实
- [ ] 结论中的"未来工作"是否与正文的"局限性"对应

## 三、领域特有评审维度（P1-7）

根据论文的学科领域，加载额外的评审维度。详见 `references/domain_profiles.md`。

| 领域 | 特有维度 | 说明 |
|------|---------|------|
| CS/工程 | 可复现性 | 实验参数是否完整、代码是否可用、数据集是否标注 |
| 医学 | 伦理合规 | 伦理审查声明、知情同意、临床试验注册 |
| 社科 | 数据规范性 | 数据来源说明、样本代表性、研究伦理 |
| 人文 | 引文深度 | 文本细读深度、引文准确性、论证密度 |

## 四、查重检测规则

### 4.1 内部查重

检测当前章节与共享上下文中已有章节的重复度。

| 重复率 | 判定 | 处理方式 |
|--------|------|---------|
| < 5% | 正常 | 通过 |
| 5%-15% | 警告 | 标记并建议修改重复段落 |
| 15%-30% | 需修改 | 退回智能体三，要求改写重复部分 |
| > 30% | 严重 | 退回智能体三，要求重写 |

### 4.2 自查重

检测单章节内部的重复表述。

- 同一段落内相同句式重复 > 3 次 → 标记
- 相同观点在不同段落重复表达 > 2 次 → 标记
- 相同引用在非必要情况下重复 > 3 次 → 标记

## 五、引用真实性校验（P0-1）

### 5.1 校验规则

| 检查项 | 判定 | 处理方式 |
|--------|------|---------|
| `[CITE:ref_id]` 在文献池中存在 | 通过 | 正常处理 |
| `[CITE:ref_id]` 在文献池中不存在 | **fabricated** | 直接 reject，退回智能体三 |
| `[REF_NEEDED:描述]` 标记合理 | 通过 | 保留标记，汇总为需核实清单 |
| `[REF_NEEDED:描述]` 标记过多（>总数30%） | 警告 | 建议用户补充文献 |

### 5.2 校验输出

```yaml
citation_verification:
  total_citations: N
  verified: N           # 在文献池中验证通过的
  ref_needed: N         # 标注为 REF_NEEDED 的
  fabricated: N         # 虚构文献数量（必须为 0）
```

## 六、问题严重等级定义

| 等级 | 说明 | 处理方式 |
|------|------|---------|
| **critical** | 导致论文无法使用的问题：核心论点错误、数据造假、严重逻辑矛盾、**虚构文献** | 必须修复，不修复则 reject |
| **major** | 显著影响论文质量：章节缺失、引用错误、逻辑断裂 | 应修复，未修复则 revise |
| **minor** | 轻微瑕疵：格式不统一、个别措辞不当、标点错误 | 建议修复，不强制 |

```
[评分]：
  完整性：★X — 评语
  正确性：★X — 评语
  学术规范性：★X — 评语
  语言质量：★X — 评语

  总引用数：N | 已验证：N | 需核实：N | 虚构：N

  2. ...

  1. ...

```
